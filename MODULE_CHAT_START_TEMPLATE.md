# Запуск чата академии

После добавления PROJECT_INSTRUCTIONS_SHORT.md в настройки проекта достаточно одного сообщения.

- Новый модуль: «Начинаем M00. Восстанови состояние и проведи меня через первый доступный шаг».
- Отдельный чат урока: «Продолжаем M00-L01. Проверь Tracker и продолжи с последнего сохранённого шага».
- Возврат без ID: «Продолжим». Если записи указывают на несколько независимых незавершённых работ и выбор влияет на задачу, задай один уточняющий вопрос.
- Перед переносом в старом чате: «Сохрани точку продолжения этого урока для нового чата».

Порядок восстановления и границы ответственности описаны в [контракте](MODULE_CHAT_CONTRACT.md).
