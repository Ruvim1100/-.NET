# M00-L01 · Проверка среды

1. Откройте PowerShell или терминал в новой пустой рабочей папке. Запустите по очереди dotnet --version, dotnet --list-sdks и dotnet --list-runtimes. Сохраните выбранный SDK и строки Microsoft.NETCore.App. Пути с именем пользователя можно убрать.

2. До сборки запишите прогноз: позволит ли выбранный SDK собрать net11.0? Если SDK 11 доступен, создайте тестовый проект командой dotnet new console -n OrderProbe -f net11.0. Перейдите в папку OrderProbe. Выполните dotnet build, затем dotnet run --no-build.

3. Измените текст, который печатает Program.cs. До эксперимента запишите прогноз для dotnet run --no-build. Выполните команду, затем dotnet run. Сравните вывод.

4. Передайте на review версии, прогноз, фактический вывод двух запусков и объяснение в 2–3 предложениях. Если команда недоступна или выбран SDK старше по возрасту, пришлите первую ошибку и объясните, на каком этапе остановились. Отсутствие SDK — допустимый диагностический результат.

Критерии: воспроизводимая последовательность, строка вывода или ошибка и собственное объяснение. Автотесты для этой диагностической работы не требуются. Граница эксперимента — framework-dependent консольное приложение в Debug без смены TFM.
