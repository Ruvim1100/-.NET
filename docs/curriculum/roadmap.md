# Программа академии

Сквозной проект — сервис заказов. Сначала рассчитываем стоимость в консоли, затем переносим правила в библиотеку, добавляем HTTP, PostgreSQL и интерфейс Next.js. В конце защищаем эксплуатационные решения. Время ориентировочное. На каждый модуль отводим 20% теории, 60% самостоятельной работы, 10% проверки и 10% повторения.
