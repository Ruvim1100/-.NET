# Выбор учебных материалов

|Материал|Что берём в программу|Как проверяем перенос знания|Ограничение|
|---|---|---|---|
|First steps with C# (Microsoft Learn)|Небольшие упражнения на значения и управление потоком|Изменить границу диапазона и предсказать вывод|Опытный разработчик проходит выборочно по диагностике|
|Build .NET applications with C# (Microsoft Learn)|Инструменты и управление зависимостями|Восстановить новый проект и объяснить assets-файл|Версию SDK сверяем с матрицей|
|ASP.NET Core fundamentals (Microsoft Learn)|Наращивать pipeline по одному компоненту|Предсказать short-circuit и проверить запросом|Упражнение само по себе не проверяет поведение при отказе|
|C# for Beginners (Microsoft, видео)|Краткая демонстрация перед самостоятельным опытом|Воспроизвести вывод с другим входом|Видео о базовом синтаксисе; новинки сверяем по reference|
|eShop (.NET, reference application)|Сравнение AppHost, серверных тестов и browser journeys|Объяснить, какие зависимости нужны каждому тесту|Облачные контейнеры из примера предназначены для демонстрации|
|BenchmarkDotNet (руководство проекта)|Условия осмысленного измерения в Release|Повторить эксперимент и объяснить разброс|Для production-вывода нужен профиль реальной нагрузки|

Ссылки и статус проверки перечислены в [каталоге](source-catalog.md). Глубина проверки — программа, раздел руководства или README; полного прохождения внешних курсов не проводилось.
